# Front-end Learning Projects

Small browser projects built from scratch while learning HTML, CSS, and vanilla
JavaScript. Each folder is self-contained and can be opened directly in a
browser.

## Projects

| Project | Focus |
|---|---|
| [`PriceRangeSlider`](PriceRangeSlider/) | Two-handle price filtering and interactive UI state |
| [`Loremipsum`](Loremipsum/) | DOM scripting and generated text interaction |

## Run locally

Clone the repository and open a project's `index.html` file, or serve the root
with any static web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/PriceRangeSlider/` or
`http://localhost:8000/Loremipsum/`.

## Purpose

This is a learning archive that shows incremental front-end practice. Future
iterations may add responsive styling, accessibility checks, and automated UI
tests.
